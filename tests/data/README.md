# Test data

| Folder | Content |
|---|---|
| `songs/` | The test songs: synthetic sequences, public-domain arrangements and engine test songs, written for this repository |
| `cakewalk/` | What the Cakewalk programs made of them: saved files, edited files, captured MIDI output |
| `ttsseq/` | What the engine DLLs answer when called directly: the oracle sets of versions 1.01, 2.10 and 3.00 |

Nothing here is a Cakewalk file: no program, DLL or sample song from Cakewalk's disks. How each
observation was made is in `docs/reverse-engineering/`.
